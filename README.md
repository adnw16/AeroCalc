# Airfoil-surface-area-to-volume-calculator-shape-optimiser

Please read the pdf to gain an understanding of my project. Please note that the calculator currently only works on symmetrical airfoils. Implementation analysis on non-symmetrical airfoils is being worked on.

This was a short project aimed to automate the manual process that I went through in the PDF. The plotting and results display was generated by AI written code.

To use the calculator, simply run the calculator file with your desired name in the command-line argument.
